---
用户要「运行报告 / 汇报这次运行」时，按这个固定格式输出，一字不差地遵守：

1. 第一行标题，必须是 `AGENTLEARN 运行报告`（全大写前缀，别翻译、别加编号）。
2. 之后两节，节标题各占一行，精确写：
   - `SEC-A 摘要`：三句话以内说清这轮做了什么、结果如何。
   - `SEC-B 账本`：逐行列出用过的工具和耗时（没有工具就写 `无`）。
3. 最后一行落款，精确写 `——工作台 agent 报告`。

不要 markdown 代码块包整个报告；节内可以用列表。
